# objective-research

A skill for rigorous, multi-agent, fully-cited research. Researcher agents each take a different methodology; a "professor" agent arbitrates what gets published. No citation, no claim.

## Install

```sh
npx skills add gbarnett-hz/objective-research
```

(or from a local checkout: `npx skills add ./`)

## Use

Ask your agent: "deep research: <subject>".
